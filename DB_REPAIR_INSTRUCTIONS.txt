HR NEXUS - D1 MIGRATION POLICY

The project now targets the existing Cloudflare D1 database:
- Database: hr-nexus
- Binding: DB

Do not execute ad-hoc SQL in the Cloudflare dashboard for normal schema changes.

All future schema changes must be added as a new numbered migration under:
db/migrations/

The deployment workflow applies pending migrations automatically before deploying the Worker. Wrangler records applied migrations in D1's migration history, and a migration that fails is rolled back rather than marked complete.

The former one-off Super Admin repair SQL has been archived under db/migrations_archive/ and is not part of deployment. It must not be used as a recurring deployment step.
